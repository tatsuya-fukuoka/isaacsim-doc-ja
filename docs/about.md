# このサイトについて

## 位置づけ

本サイトは、NVIDIA Isaac Sim を日本語で学ぶための**非公式ガイド**です。以下の方針で運営しています。

- 公式ドキュメントの**逐語訳ではなく**、章立てを参考にした**独自執筆の解説**を掲載します
- 各ページに対応する公式ドキュメントへのリンクを併記し、一次情報へ誘導します
- 仕様・API・バージョンに関する正確な情報は、常に公式ドキュメントを優先してください
