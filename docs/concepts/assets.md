# アセットとコンテンツ

!!! info "対応する公式ドキュメント"
    [Isaac Sim — Assets](https://docs.isaacsim.omniverse.nvidia.com/latest/assets/index.html)

Isaac Sim には、ロボット・環境・小物(props)・マテリアルなど、すぐに使える USD アセットが多数用意されています。

## アセットの入手経路

| 経路 | 説明 |
| --- | --- |
| **クラウドアセット** | NVIDIA がホストするアセットサーバーから直接参照。既定の設定で Content Browser から閲覧可能 |
| **ローカルへのダウンロード** | アセットパックをまとめてダウンロードし、ローカル/社内サーバーに配置。オフライン環境や高速化に有効 |
| **自作・外部アセット** | CAD や DCC ツールから変換した USD、URDF からのインポートなど |

!!! tip "オフライン環境での利用"
    クラウドアセットへの接続が遅い・不可能な環境では、アセットパックをローカルに展開し、Isaac Sim の設定でアセットルートパスをローカルパスに変更します。

## 付属アセットの代表例

### ロボット

- **マニピュレータ**: Franka(パンダアーム)、UR シリーズ、その他各社アームなど
- **モバイルロボット (AMR)**: 差動二輪ロボット、倉庫向け AMR、フォークリフト型など
- **ヒューマノイド / 四足**: 研究用途で使われる各種ヒューマノイド・四足ロボット
- **グリッパー / ハンド**: 平行グリッパー、多指ハンド

### 環境

- シンプルな部屋・グリッド環境(動作確認用)
- 倉庫(warehouse)環境 — AMR のナビゲーション検証の定番
- 工場・オフィスなどの大規模環境

### 小物 (Props)

- パレット、棚、箱、コンテナなどの物流系オブジェクト
- YCB オブジェクト(把持研究の標準データセット)など研究用小物

## アセットの配置方法

1. **Content Browser** で目的のアセット(`.usd`)を探す
2. ステージへ**ドラッグ&ドロップ**する(Reference として追加される)
3. 位置・回転・スケールを Property パネルで調整する

参照 (Reference) で配置されたアセットは元ファイルとリンクしており、元アセットの更新がシーンに反映されます。

## 外部データからアセットを作る

| 元データ | 方法 |
| --- | --- |
| URDF / MJCF | [ロボットインポーター](../robots/import.md) で変換 |
| CAD (STEP など) | CAD コンバーター拡張や DCC ツール経由で USD 化 |
| メッシュ (OBJ / FBX / glTF) | Isaac Sim / Omniverse のアセットコンバーターで USD 化 |

変換後は、単位(メートル)・アップ軸(Z)・スケールの確認を忘れずに行ってください。

## SimReady アセット

NVIDIA が提唱する **SimReady** は、「シミュレーションでそのまま使える」ことを目指したアセット規格です。物理属性(質量・コライダー)やセマンティクスラベルが付与済みで、合成データ生成やロボット検証にすぐ投入できます。
