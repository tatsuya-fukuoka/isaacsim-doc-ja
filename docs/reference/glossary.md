# 用語集

Isaac Sim / Omniverse でよく登場する用語の日英対照と簡単な説明です。

| 用語(英語) | 日本語 / 読み | 説明 |
| --- | --- | --- |
| Stage | ステージ | 開いているシーン全体。USD レイヤーの合成結果 |
| Prim | プリム | ステージ上のノード。すべてのオブジェクトの基本単位 |
| Xform | エックスフォーム | 位置・回転・スケールを持つ変換ノード |
| Layer | レイヤー | USD の編集単位(≒ファイル)。重ねて合成される |
| Reference | 参照 | 別 USD ファイルをシーンへ取り込む合成機構 |
| Payload | ペイロード | 遅延読み込み可能な参照 |
| Variant | バリアント | アセット内の切り替え可能な構成 |
| OpenUSD | オープンユーエスディー | Pixar 発のシーン記述規格。Omniverse の中核 |
| Kit | キット | Omniverse アプリの基盤フレームワーク |
| Extension | 拡張機能 | Kit 上のプラグインモジュール |
| OmniGraph / Action Graph | オムニグラフ | ノードベースのビジュアルプログラミング機構 |
| PhysX | フィジックス | NVIDIA の物理エンジン |
| Physics Scene | 物理シーン | 重力・ソルバー設定を持つ物理設定プリム |
| Rigid Body | 剛体 | 質量を持ち物理法則で動く物体 |
| Collider | コライダー | 衝突判定形状 |
| Articulation | アーティキュレーション | リンクと関節からなる関節系(ロボットの物理表現) |
| Joint Drive | ジョイントドライブ | 関節を目標値へ駆動する仕組み(Stiffness/Damping) |
| Physics Material | 物理マテリアル | 摩擦係数・反発係数の設定 |
| RTX LiDAR | アールティーエックス ライダー | レイトレーシングによる LiDAR シミュレーション |
| Annotator | アノテーター | 正解データ(BBox、セグメンテーション等)の取得器 |
| Writer | ライター | 合成データのファイル出力器 |
| Domain Randomization | ドメインランダマイゼーション | 学習データの多様化のためのランダム化手法 |
| Replicator | レプリケーター | 合成データ生成フレームワーク |
| SDG | 合成データ生成 | Synthetic Data Generation の略 |
| ROS 2 Bridge | ロス2ブリッジ | ROS 2 通信を行う拡張機能 |
| use_sim_time | — | ROS 2 側でシミュレーション時刻を使う設定 |
| Isaac Lab | アイザックラボ | RL / IL 向け学習フレームワーク |
| SimReady | シムレディ | 物理・ラベル付与済みのシミュレーション用アセット規格 |
| Nucleus | ニュークリアス | (旧世代の)Omniverse アセット共有サーバー |
| Headless | ヘッドレス | GUI 無しでの実行形態 |
| Livestream / WebRTC Client | ライブストリーム | ヘッドレス実行画面をリモート表示する仕組み |
| USD Composer / DCC | — | シーン編集用の周辺ツール群 |
