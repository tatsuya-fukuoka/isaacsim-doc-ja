# 概要と特徴

!!! info "対応する公式ドキュメント"
    [Isaac Sim Documentation — Introduction](https://docs.isaacsim.omniverse.nvidia.com/latest/introduction/index.html)

## Isaac Sim とは

Isaac Sim は、NVIDIA Omniverse プラットフォーム上に構築された**ロボティクス・シミュレーションアプリケーション**です。ロボット開発における「実機を使う前の検証」「学習データの生成」「アルゴリズムのテスト」を、物理的に正確かつフォトリアルな仮想環境で行えます。

Isaac Sim 4.5 以降はオープンソース化が進み、[GitHub (isaac-sim/IsaacSim)](https://github.com/isaac-sim/IsaacSim) でソースコードが公開されています。

## 主な特徴

### 1. OpenUSD ベースのシーン記述

シーン(ステージ)は **OpenUSD (Universal Scene Description)** で記述されます。レイヤー合成・参照・バリアントといった USD の仕組みにより、大規模なシーンを分割管理したり、複数人で共同編集したりできます。

### 2. PhysX による物理シミュレーション

NVIDIA **PhysX** を物理エンジンとして採用し、剛体・関節(Articulation)・接触・摩擦・変形体などを GPU アクセラレーションでシミュレートします。ロボットアームの関節駆動や移動ロボットのホイール接地など、ロボティクスに必要な物理挙動を高精度に扱えます。

### 3. RTX レンダリングとセンサーシミュレーション

RTX GPU のレイトレーシング/パストレーシングにより、フォトリアルな画像を生成できます。これはカメラ映像の見た目だけでなく、**RTX LiDAR** や **RTX Radar** のようなレイトレーシングベースのセンサーシミュレーションにも使われます。

### 4. 合成データ生成 (Synthetic Data Generation)

**Omniverse Replicator** を利用して、物体の位置・照明・テクスチャなどをランダム化(ドメインランダマイゼーション)しながら、バウンディングボックス・セグメンテーション・深度などのアノテーション付き学習データを大量生成できます。

### 5. ROS 2 連携

ROS 2 ブリッジを通じて、シミュレーション内のセンサーデータ(カメラ、LiDAR、IMU など)を ROS 2 トピックとしてパブリッシュし、ROS 2 ノードからロボットを制御できます。SIL(Software-in-the-Loop)テストに活用できます。

### 6. 強化学習との統合

姉妹フレームワークの **Isaac Lab** と組み合わせることで、GPU 並列による高速な強化学習・模倣学習環境を構築できます。

## ユースケース

| ユースケース | 概要 |
| --- | --- |
| マニピュレーション検証 | ロボットアームの把持・組立動作の事前検証 |
| AMR / AGV の走行検証 | 倉庫・工場環境での自律移動ロボットのナビゲーションテスト |
| 合成データ生成 | 物体検出・セグメンテーション用の学習データ作成 |
| 強化学習 | Isaac Lab による歩行・マニピュレーションポリシーの学習 |
| デジタルツイン | 実際の工場・倉庫を再現した大規模シミュレーション |

## アーキテクチャの概観

Isaac Sim は Omniverse **Kit** という拡張可能なアプリケーションフレームワーク上に構築されています。機能のほとんどは **Extension(拡張機能)** として実装されており、必要な機能だけを有効化した軽量なアプリケーション構成を作ることも可能です。

```
┌─────────────────────────────────────┐
│    Isaac Sim(アプリケーション)      │
│  ┌──────────┐ ┌──────────┐          │
│  │ Robot     │ │ Sensor   │  ...     │  ← Extensions
│  │ Importer  │ │ Simulation│         │
│  └──────────┘ └──────────┘          │
├─────────────────────────────────────┤
│  Omniverse Kit(アプリ基盤)          │
├───────────┬───────────┬─────────────┤
│  OpenUSD  │  PhysX    │ RTX Renderer │
└───────────┴───────────┴─────────────┘
```
